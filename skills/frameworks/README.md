# Framework skills

Framework-specific conventions, architecture guidance, structure rules, and implementation patterns.

These skills help AI systems align with framework-specific development workflows while preserving maintainability, consistency, and predictable code organization.

## Current focus

- Flutter
- React
- component structure
- state management patterns
- project organization

## Philosophy

Framework skills should:

- Prefer maintainable patterns over trendy abstractions
- Follow framework conventions when practical
- Reduce hidden behavior and magic
- Keep component and state boundaries predictable
- Optimize for readability and long-term evolution

## Skills

- **[file-structure](./file-structure/SKILL.md)** — File organization rules for maintainable component and class structure.
- **[react-component-ownership](./react-component-ownership/SKILL.md)** — Apply ownership-boundary principles to React state, effects, queries, dialogs, tabs, forms, and component composition.
- **[shadcn-ui](./shadcn-ui/SKILL.md)** — Use a registry-first workflow for shadcn/ui: reuse local primitives, verify the current official registry, prefer the official CLI, and hand-roll only when necessary.
